**Tools for variance-based sensitivity analysis in causal effect estimation**

Sam Pimentel, Professor    
Statistics 

Estimating the causal effects of a treatment (compared to a control condition) is an important task in the social and medical sciences. However, unless the treatment was assigned randomly to subjects it can be difficult to establish whether apparent effects are due to treatment or due to unmeasured confounding variables. Sensitivity analysis investigates how strong an unmeasured confounding variable would have to be to explain away an observed effect. This project focuses on developing and testing software for a new sensitivity analysis technique called variance-based sensitivity analysis to make it accessible to public health researchers and applied social scientists.

**Role:** The student researcher will have the following responsibilities:

1\. Carefully review and understand existing manuscripts and R packages/codebases about variance-based sensitivity analysis and related methods for sensitivity analysis and inverse propensity score weighting.

2\. Using the research group’s internal code as a starting point, create and test an R package implementing variance-based sensitivity analysis (and related methods including bootstrap confidence intervals) for an applied audience, testing it on a canonical dataset about the impact of diet on blood mercury.

3\. Review open-source social science depositories to identify a new open-source dataset compatible with the dataset and test the software methods on this data.

4\. Draft a software vignette demonstrating the use of the software on the newly-identified data.

Anticipated deliverables include an open-source R package to be published on the Comprehensive R Archive Network (CRAN) and possibly (depending on the skill and motivation of the student) a manuscript to be submitted to a statistical software journal.

By the end of the project, I anticipate that the student researcher will gain:

\- Deep familiarity with the practice and theory of causal effect estimation and sensitivity analysis.

\- Experience designing, implementing and testing statistical software in R, including computational bootstrap methods.

\- Skills in technical writing for audiences with diverse academic backgrounds.

**Qualifications:** Required: strong background in statistics and/or machine learning. Desirable: coursework in mathematical statistics, linear modeling, and causal inference (such as Stat 135, Stat 151A, and Stat 156).

**Required:** strong background in programming and some familiarity with R.  
**Desirable:** Stat 133 or equivalent course, experience developing R packages.

**Required:** interest in statistical methodology (including reading technical academic papers) and in social and medical applications of causal inference.

**Required:** advanced proficiency in version control using Git and GitHub.
